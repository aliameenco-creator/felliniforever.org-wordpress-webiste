=== Fellini Forever ===
Requires at least: 6.6
Requires PHP: 8.1
Version: 0.1.0
License: GPL-2.0-or-later

Custom WordPress theme made from the authorized Fellini Forever archive.
Install the theme, activate it, then Appearance > Fellini Forever Setup.
Setup creates editable original pages, preserves existing edits and imports images.
Set the form destination under Settings > General when ready.
Archived placeholder articles remain drafts. Original noindex is preserved until launch.
External 3D viewers and YouTube videos load only on interaction.
Theme updates are available under Appearance > Fellini Forever Updates.
